# One Word From Your Ex

This entry writes exactly one word to `entry.txt` and nothing else — no extra files, no trailing newline, no explanation. One word your ex would use to describe you, exactly as the bounty asks.

```
regifted
```

The word: you were the gift nobody wanted — unwrapped once, then passed on to the next person. It stings because it is true, and it lands four weeks before Christmas, when regifting season is at its peak.

## How it works

```bash
MAKEFUN_OUTPUT_DIR=/tmp/oneword-ex-out node main.ts
```

This creates the output directory if needed and writes the word `regifted` to `entry.txt` inside it.
